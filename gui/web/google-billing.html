Google 调用渠道与余额

优先使用适用的 Cloud 赠金，再选择 Gemini API 预付余额。余额未知或过期时，自动模式暂停请求，等待同步。

1 · 连接 Google 项目

先在 Agent 管理保存官方 Gemini 连接，基础地址填写 https://generativelanguage.googleapis.com/v1beta/openai。

Vertex 使用本机 Google Cloud 凭据。安装 Google Cloud CLI 后运行：

gcloud auth application-default login

需要启用 aiplatform.googleapis.com 和 cloudbilling.googleapis.com；登录身份需要项目的模型调用权限、结算账号读取权限。自动切到 Developer 时还会核对 API Key 所属项目。

2 · 同步余额与赠金

Google 公开结算 API 不返回控制台里的完整剩余赠金与 AI Studio 预付余额。使用配套浏览器扩展，从你登录的官方账单页读取。

  1. 在 Chrome / Edge 的扩展管理中打开开发者模式，选择「加载已解压的扩展」，加载下方目录。
  2. 点击下方「与已安装扩展配对」，启用每 5 分钟刷新账单页；也可在扩展弹窗中手动配置。
  3. 打开下方 Cloud 赠金页或 AI Studio 账单页，确认完整赠金 ID、币种、适用范围和到期日期显示。AI Studio 页面须显示结算账号 ID；扩展会读取其中 Google Payments 内嵌账单的预付余额，并核对两个页面的账号一致。

配对码只允许扩展向本机写入余额，不能读取聊天和 API 密钥。浏览器登录状态保留在浏览器内。

3 · 当前读数

快照有效期为 10 分钟。账单数据可能延迟；这不是扣费硬上限。手动指定渠道按 Google 正常计费，余额不足时可能从付款方式扣款。
