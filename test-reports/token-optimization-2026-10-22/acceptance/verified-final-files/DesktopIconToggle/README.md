# DesktopIconToggle

隔离交付的示例项目：双击 Windows 桌面空白处，切换 Explorer 桌面图标的显示 / 隐藏。

运行入口只有显式的 `--run` 模式；`--check` 是纯只读环境检查。控制台程序形态保留，因此未来实际双击启动时可能短暂出现控制台窗口。

## 参数

| 参数 | 行为 |
| --- | --- |
| 无参数 / `--help` / `-h` / `/?` | 打印使用说明后退出，退出码 0 |
| `--check` | 只读检查：Windows 环境、explorer.exe 进程、`SHELLDLL_DefView`、`SysListView32`、桌面宿主窗口与图标视图属主。打印结果后退出；不弹窗、不写文件、不改桌面、不装钩子、不建实例锁、不进消息循环、不申请跨进程写内存权限 |
| `--run` | 单实例运行：初始化时直接隐藏桌面图标，安装低级鼠标钩子，按系统双击时间与位置容差识别双击，命中桌面空白区域时切换一次 |
| 其他参数 / 多余参数 | 打印说明，退出码 2 |

参数解析先于任何运行初始化；只接受一个模式参数。

## 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 帮助正常结束，或所请求操作成功 |
| 2 | 参数无效（未知、缺失或多余） |
| 3 | Explorer 未运行 |
| 4 | 桌面窗口缺失、失效或属主校验失败 |
| 5 | 已有运行实例 |
| 6 | 鼠标钩子安装失败 |
| 7 | 不支持的操作系统 |
| 8 | 其他初始化或运行错误 |

同一组退出码同时写在源码 `Usage()` 输出中。

## 构建

```bat
cmd.exe /d /c DesktopIconToggle\build.cmd
```

- 脚本用自身所在目录定位源码、manifest 与输出目录，路径完整加引号，支持项目目录含空格。
- 优先使用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`；缺失时回退到本机 Framework 对应编译器；不安装、不下载任何内容。
- 使用 .NET Framework 自带编译器与系统 `System.dll`，通过 `/win32manifest` 把 manifest 嵌入 EXE。
- 输出目录存在时跳过创建，仅在实际创建失败时报告该错误；条件失败分支均为带括号的分组块，不依赖旧的 `errorlevel`。
- 编译器或输入文件缺失、目录创建失败、编译失败、产物缺失均返回非零退出码；构建成功返回 0。不生成调试符号等额外产物，也不自动启动程序。

## 检查（宿主验收）

从项目根目录依次执行，第一条成功后再执行第二条：

```bat
cmd.exe /d /c DesktopIconToggle\build.cmd
DesktopIconToggle\bin\DesktopIconToggle.exe --check
```

第二条不使用 `start` 包装，也不执行 `--run`。两条均返回 0 才表示本次构建与只读检查通过。

`--check` 通过只表示当前环境的 Explorer 进程、桌面窗口与属主关系可识别，不证明双击恢复、遮挡排除、Explorer 重启、多显示器或 DPI 交互已经实测。

## 默认隐藏

`--run` 记录进入前的实际可见状态（`IsWindowVisible`），随后显式发送隐藏（`SW_HIDE`）——不是“切换一次”，因此原本已显示时也一定会隐藏。

## 双击识别

- 系统双击时间上限 `GetDoubleClickTime()`；位置容差取 `SM_CXDOUBLECLK` / `SM_CYDOUBLECLK` 的一半。两次按下都必须是空白桌面点击才算配对成功，无效点击中断配对。
- 每次配对成功只切换一次，之后清除配对状态。
- 显示 / 隐藏两种命中策略：
  - **图标显示时**：`WindowFromPoint` 必须命中已核实的图标视图 `SysListView32`，并对其发送 `LVM_HITTEST`，`iItem == -1` 才视为空白（排除桌面图标）。
  - **图标隐藏时**：不要求命中已隐藏的 `SysListView32`，也不对它做项目命中测试；只允许命中已核实的 `SHELLDLL_DefView` 或其桌面宿主窗口，并检查坐标落在该窗口客户区内。这是隐藏后仍能双击恢复的关键修补。
- 启动时保存图标视图、`SHELLDLL_DefView` 及准确的宿主关系，并在每次处理前核对窗口仍存在、父子关系未变、属主仍是同一 Explorer 进程。任意 `WorkerW`、任意祖先窗口或被其他应用遮挡的坐标都不视为桌面空白；任务栏、桌面图标及其他应用中的点击不触发切换。
- 钩子回调保持简短：仅把点击坐标入队并唤醒消息线程，跨进程命中测试在工作循环中按事件顺序执行，并受时间预算限制；超时、权限不足或窗口失效时放弃该次切换。
- 钩子始终调用 `CallNextHookEx`，不吞掉任何鼠标事件。

## 消息循环与退出

- 使用阻塞的 `GetMessage` 消息循环，周期性检查来自 `SetTimer` 的 `WM_TIMER`（约 1 秒一次），不使用 `PeekMessage` + `Sleep(20)` 轮询。
- Ctrl+C 退出请求通过 `PostThreadMessage(WM_QUIT)` 唤醒消息线程，使其正常收尾。
- 桌面窗口失效或被 Explorer 替换时，停止切换并结束监听，不自动操作未经重新验证的新窗口。

## 退出恢复与资源释放

- 正常退出、初始化失败（如钩子安装失败）或异常路径都统一释放：低级鼠标钩子、定时器、单实例互斥锁、点击队列与跨进程临时内存（`VirtualFreeEx` / `CloseHandle` / `Marshal.FreeHGlobal`）。
- 仅在原窗口身份（句柄、父子关系、属主进程）仍然有效时才把图标恢复为进入前的可见状态；原本隐藏的图标不会被强制显示。
- manifest 为 `asInvoker`、`uiAccess="false"`，并声明 Windows 兼容性与 DPI 行为，使命中判断使用一致的坐标体系。

## 交付边界

- 本次仅交付临时项目内的源码与构建产物；**未安装自启动、未创建计划任务或快捷方式、未改注册表、未运行钩子、未改变真实桌面**（构建与 `--check` 之外不执行程序）。
- 唯一构建产物为 `DesktopIconToggle/bin/DesktopIconToggle.exe`；不含服务、权限提升或自启动安装代码。
- 未来如部署开机自启动，其目标为 `DesktopIconToggle.exe --run`；本项目只作说明，不创建启动项。
