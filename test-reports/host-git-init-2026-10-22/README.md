# 0.12.3 宿主自动初始化 Git 验证

用户要求：Git 初始化由宿主负责，不能继续让用户手动执行。

## 行为

- 在执行预检中，宿主先检测所选项目的 Git 状态。目录不属于任何仓库时，由宿主运行 `git init`，然后检查宿主与执行器看到的实际根目录。
- 初始化在群聊中显示为“宿主 / 项目环境准备”，保留宿主预检记录；不调用模型、不生成新方案、不要求重复批准原有效方案。
- 同项目并发初始化串行处理；重复预检不重复初始化。
- 已有普通仓库、worktree 保留原状态。项目位于父仓库内时不创建嵌套仓库，继续提示选择实际根目录。
- 缺少 Git、权限异常、已有损坏 `.git` 或裸仓库均不自动重建。初始化失败保留原始错误，不清除现场。
- 不提交、不暂存、不添加远程地址、不上传；禁止复制用户 Git 模板文件。模型可调用的 Git 工具仍只读，不允许 `init`。
